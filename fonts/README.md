## Why this face

IBM Plex Mono is IBM's industrial monospace. Nerd Fonts renames its patched
build to Blex Mono, which respects IBM's Reserved Font Name "Plex". The `Mono`
variant keeps Nerd Font icons one cell wide, so the bar, launcher, and terminal
stay aligned.

Only Regular and Bold are bundled: the shell and terminal use those two.
Italic is not part of the theme's type scale.
